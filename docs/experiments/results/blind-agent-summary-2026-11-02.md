# 131 가상 사례 자동 블라인드 예비 검토

2026-11-02에 별도 컨텍스트의 자동 검토자가 기존 기대 라벨과 실측 결과를 보지 않고 가상 사례 5건을 판단했다. 이는 **사람의 독립 검토가 아니며** 검토자의 판단이나 신원을 도구가 인증하지 않는다. 추가 GMS 호출 없이 기존 실측 결과와 비교했다. [자동 검토 입력](blind-agent-review-2026-11-02.json), [0.65 비교](blind-agent-comparison-065-2026-11-02.json), [0.45 비교](blind-agent-comparison-045-2026-11-02.json)를 함께 보존한다.

| 사례 | 임계값 0.65 | 임계값 0.45 |
| --- | --- | --- |
| CASE-01 업로드 생성 | 설계 `1101`, `1102`와 원문 `e-post` 누락; `NO_MATCH` 판단 불일치 | 설계는 자동 검토 기대와 일치했지만 원문 `e-post` 누락 및 `e-get` 혼입 |
| CASE-02 크기 제한·작업 참조 | 설계 `1100`, `1101`과 원문 `e-limit` 누락; `NO_MATCH` 판단 불일치 | 설계 `1100`, `1101`과 원문 `e-limit` 누락 및 `e-get` 혼입 |
| CASE-03~05 | 최종 설계·원문 ID와 `NO_MATCH`가 이 자동 검토의 기대와 일치 | 동일 |

CASE-02에서 0.45의 `NO_MATCH` 표시가 자동 검토와 일치하더라도 무관한 `e-get`이 선택됐다. 표시 일치만으로 근거 관련성을 보장할 수 없다. 자동 검토자는 크기 제한 설계 `1101`을 직접 관련으로 판단했고, 이 경우 확정 명시 관계 한 단계에 따라 `1100`이 기대 결과에 포함된다. 기존 작성자 초안 라벨은 다른 직접 관련 항목을 선택했으므로 이 차이 자체를 사람이 검토해야 한다. CASE-04는 당시 다른 원문 후보가 제외된 사례여서 경쟁 검색 품질의 근거가 아니다.

비교는 최종 선택 ID와 `NO_MATCH`만 다룬다. 이전 실측에는 후보별 점수·벡터·직접 선택 이유가 남지 않아 직접 매칭의 정확도나 새 질의의 효과를 재구성하지 않는다. 저장된 fixture는 실측 기록 커밋 `52a14aa`부터 변경되지 않았고 해당 커밋의 `prepare_cases` 입력 구성과 현재 구성이 같은 것을 확인했다. 다만 과거 실측에 사례별 입력 해시가 없어 실제 공급자에 전달된 각 본문까지 증명하는 것은 아니다. 소수 합성 사례의 자동 판단을 정답이나 운영 임계값으로 채택하지 않는다.
