## 개요

AI 색인 산출물을 BE가 저장·검색 구현에 사용할 수 있도록 검증 데이터와 실행 도구를 제공하고, Markdown 검색 방식별 실제 GMS 개발용 측정 결과를 기록합니다. #130은 AI 도구·평가·인계까지로 종료하며, 실제 BE 구현과 DB 통합 검증은 별도 **S15P31A108-213**에서 이어갑니다.

## 작업 내용

- 실제 파서·청커·PreparedIndex 형식의 합성 packet과 검색/발행 검증 시나리오 26개를 제공합니다.
- 독립 baseline oracle과 Event barrier를 사용하는 승인 경합 모의 검증 6개를 구현했습니다.
- 합성 Markdown 4종·질문 12개를 고정/구조 청킹 × 문맥 보강 off/on으로 3회 비교했습니다. 실제 GMS 답변 144개, 물리 호출 150회, 공개 단가 추산 290.7104크레딧입니다.
- 원문 범위 기반 Recall/MRR, 인용·보류 검사, 실제 usage·지연·실패·코드/데이터 해시와 재생성 가능한 요약을 보존했습니다.
- 호출/비용 제한, 미확정 usage 보존, 비정상 출력 처리, 중단 체크포인트 복구와 프로필 변경 차단을 구현했습니다.

## 변경 사항·검증

- 기존 운영 라우터·공유 API·DB migration은 변경하지 않습니다. 선행 AI 모듈은 PR #21에서 제공합니다.
- 전체 AI 테스트 175개·Ruff 통과. Windows의 기존 Proactor socketpair 초기화 오류를 구분하기 위해 최종 전체 검증은 테스트 프로세스에만 Selector/session 정책을 적용했습니다. Linux CI·운영 설정은 유지합니다.
- 독립 코드 리뷰에서 발견한 응답 envelope 처리와 baseline 검증 문제는 회귀 테스트로 수정했습니다.
- 구조 설정의 API 제목 누락, source span을 건너뛴 인용 및 보류 상태/인용 규약 불일치를 기록했습니다. 합성 개발 자료의 결과이며 운영 품질·실제 DB 안전성을 보장하지 않습니다. 기본 설정은 잠정 유지합니다.

## BE 후속 연계 — S15P31A108-213

BE 인수 담당자는 후속 티켓에서 정합니다. 아래 구현과 실제 통합 시험은 #130 종료 선행 조건이 아닙니다.

| BE가 이어받을 작업 | 입력·검증 기준 |
| --- | --- |
| AI DTO·프로필 소비 | `docs/design/document-chunking-search-contract-S15P31A108-129.md`. source span은 정규화 원문의 Unicode offset이며 key/hash/profile을 보존합니다. `PreparedIndex`는 READY 발행 증거가 아닙니다. |
| 실행·상태·저장 구조 | `docs/design/document-index-refresh-contract-S15P31A108-130.md`. run/attempt/lease·SOURCE/INDEX를 분리하고 새 migration/manifest를 정합니다. |
| 원자적 발행·복구 | 기존 UNIQUE(document_version_id,chunk_no)에 맞춰 청크 전량과 READY manifest를 한 트랜잭션으로 교체합니다. 부분 배치·오래된 실행·중복 결과를 차단하고 실패 시 기존 READY를 보존합니다. |
| 범위 제한 SQL 검색 | 프로젝트·현재 멤버십·허용 버전·READY·profile 조건을 top-k 전에 적용합니다. 새 승인본 미준비 시 이전 정책으로 fallback하지 않습니다. |
| 호출 예산 | AI 전체 90초·공급자 호출별20초와 BE 기본 read timeout20초 차이를 처리합니다. 전용 timeout 또는 작업 접수 방식을 선택하고 실패/취소/usage를 기록합니다. |
| 실제 C/D 통합 시험 | 동일 fixture로 PostgreSQL/pgvector 발행·검색과 승인 경합을 재현하고, 실제 운영 경로의 품질·비용·지연을 측정합니다. 최종 baseline 검사 후 변경은 검증 snapshot으로 기록합니다. |
| 운영 비비 연결 | heading/context_refs·원문 위치를 누락하지 않고 전달하며 인용/보류 응답을 매핑합니다. 새 AI 컨텍스트·프롬프트 구현이 필요하면 관련 #90/#92 등 별도 AI 티켓으로 추적합니다. |

`ai/`에서 실행할 수 있습니다. packet 생성·기본 평가는 모델을 호출하지 않습니다. `--live`는 비용이 드는 명시적 실행입니다.

```text
python -m scripts.prepare_tokenizer
python -m scripts.generate_retrieval_handoff --output <경로>/handoff.json
python -m evaluations.document_rag --output <새 경로>/dry.json
python -m evaluations.summarize <기존 실측 JSON> --output <경로>/summary.md
```

상세 인계: `ai/evaluations/README.md`, `docs/experiments/document-rag-evaluation-S15P31A108-130.md`. 측정 자료: `docs/experiments/results/S15P31A108-130-rag-dev-v1.json` 및 `-summary.md`. 정답 라벨/운영 자료 검토와 운영 채택 기준은 후속 통합 작업에서 정합니다.
