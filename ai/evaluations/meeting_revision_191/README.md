# 191번 회의→문서 수정안 재사용 탐색

`reuse_probe.py`는 **제품 경로나 계약 구현이 아닌 합성 자료·가짜 모델을 이용한 탐색용 스크립트**다. 190 회의 분석 결과를 가상으로 확인한 뒤, dev에 병합된 138 입력 변환 → 191 연결부 → 137 문서 수정안 생성 함수를 차례로 호출한다. 결정 승인·회의 ID와 근거 발언의 실제 저장은 시험하지 않는다.

137과 138은 dev에 병합됐다. 해당 변경이 포함된 작업 사본의 `ai/`에서 실행한다.

```powershell
python -m evaluations.meeting_revision_191.reuse_probe
```

실제 GMS 호출이나 저장은 없다. 모델이 만든 문자열을 검증된 결정으로 바로 사용하는 방식은 합의된 계약이 아니다. 이 샘플은 가상의 회의 결정이 이미 확인되었다고 **가정**해 전달한다. 잘못된 문서 버전·미선택 블록·없는 근거도 거부되는지 확인한다.

137의 결정 입력·출력에는 회의 발언 ID가 없고, 190 결과의 결정 역시 문자열이라 둘의 연결이 검증되지 않는다. 실제 기능을 완성하려면 BE·FE의 결정 확인, 회의 발언 ID 연결, 최신 기준·권한 재확인 및 초안 저장 계약이 필요하다. 현재 dev에 병합된 138→191→137의 함수 조합은 별도의 자동 테스트에서 합성 입력과 가짜 모델로 확인했다. 그 시험 역시 실제 회의의 사용자 확인·DB·권한·저장·승인 또는 실제 GMS 호출을 검증하지 않는다.
