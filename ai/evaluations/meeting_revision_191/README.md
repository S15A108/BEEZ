# 191번 회의→문서 수정안 재사용 탐색

`reuse_probe.py`는 **제품 경로나 계약 구현이 아닌 합성 자료·가짜 모델을 이용한 탐색용 스크립트**다. 현재 dev의 190 회의 분석 결과를 가상으로 확인한 뒤, 191 내부 연결부를 거쳐 별도 137 작업 브랜치의 문서 수정안 생성 함수를 호출한다. 실제 138 입력 변환·결정 승인·회의 ID와 근거 발언의 저장은 대신하지 않는다.

137은 아직 dev에 없으므로 이 스크립트는 dev 단독 환경에서 실행되지 않는다. 두 구현이 들어 있는 격리된 테스트 사본의 `ai/`를 작업 디렉터리로 삼고 다음처럼 원본 스크립트를 실행한다.

```powershell
python C:\path\to\reuse_probe.py
```

`PYTHONPATH`가 그 사본의 `ai/`를 가리켜야 한다. 실제 GMS 호출이나 저장은 없다. 모델이 만든 문자열을 검증된 결정으로 바로 사용하는 방식은 합의된 계약이 아니다. 이 샘플은 가상의 회의 결정이 이미 확인되었다고 **가정**해 모듈 간 입력을 손으로 연결한다. 잘못된 문서 버전·미선택 블록·없는 근거도 거부되는지 확인한다.

137 브랜치의 결정 입력·출력에는 회의 발언 ID가 없고, 190 결과의 결정 역시 문자열이라 둘의 연결이 검증되지 않는다. 실제 기능을 완성하려면 138·BE의 결정 확인, 회의 발언 ID 연결, 최신 기준·권한 재확인 및 초안 저장 계약이 필요하다. 상대 브랜치가 바뀌면 이 탐색 스크립트가 실패할 수 있으며 현재 dev가 해당 인터페이스를 약속한다는 뜻은 아니다.
