# 나래 문서 API 명세

모든 경로는 실험용 API이며 실제 BEEZ 공통 API 계약을 변경하지 않는다. 같은 경로라도 HTTP 메서드가 다르면 서로 다른 기능이다.

## POST /api/projects/{projectId}/documents

프로젝트에 문서를 생성한다. 로그인 세션과 활성 프로젝트 멤버십이 필요하다. 요청에는 UTF-8 Markdown 파일을 넣는다. 클라이언트가 보낸 projectId만 믿지 않고 서버가 프로젝트 접근 권한을 확인한다.

### 요청

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| file | binary | Y | 업로드할 Markdown 원문 |
| kind | string | Y | PLAN, REQUIREMENTS, API_SPEC, ERD 중 하나 |
| title | string | Y | 문서 제목 |

### 성공 응답

문서 생성 성공은 HTTP 201이며 documentVersionId를 반환한다.

이 응답은 원문 버전의 생성 성공이며 색인 완료를 의미하지 않는다. 검색 준비 상태는 별도 필드로 확인한다. 처리 일부가 실패하면 생성 성공의 의미를 임의로 바꾸지 않는다.

### 오류

인증 세션이 없으면 401, 업로드 한도 초과는 413을 반환한다.

허용 형식 위반과 필수 필드 누락은 400이다. 다른 프로젝트에 접근하는 경우의 오류 본문은 공통 권한 정책을 따른다. 이 문서에는 자동 재시도 횟수나 삭제 경로를 정의하지 않는다.

## GET /api/projects/{projectId}/documents

GET은 문서 목록을 조회하며 새 문서를 생성하지 않는다.

목록에는 접근 가능한 문서의 제목과 버전 상태만 포함한다. 문서 원문 전체를 목록 응답에 넣지 않는다. 페이지 이동 시 정렬 기준과 커서를 동일하게 유지한다. GET 요청의 성공 코드는 200이며, 결과가 없으면 빈 목록이다.

## DELETE 동작

문서 삭제 API의 경로와 메서드별 상세 응답은 아직 합의하지 않았다. POST 생성 경로를 삭제 경로로 추측하지 않는다.
