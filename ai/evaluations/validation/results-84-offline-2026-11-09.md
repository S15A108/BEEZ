# 검증 AI 기존 평가 재집계 (S15P31A108-84)

## 범위

2026-10-29에 저장된 합성 사례 결과를 2026-11-09에 오프라인으로 다시 집계했다. **이번 작업에서 모델을 호출하지 않았다.** 기존 실험은 FastAPI 테스트 전송과 주입된 OpenAI provider를 사용했으며 운영 GMS, 실제 검색·BE·DB 전체 경로의 검증이 아니다. 자세한 당시 실행과 격리 DB 경계는 [기존 평가](results-2026-10-29.md) 및 [DB 연동 평가](results-db-e2e-2026-10-29.md)에 있다.

네 사례는 프롬프트 보완에도 쓰인 비독립 합성 사례다. 아래 건수는 이 사례·실행에서 정한 기준에 대한 기록이며 운영 오탐률이나 재현율이 아니다. 정상의 오탐은 BLOCKING finding이 있는 경우만 센다. 정책 미정·불일치·원문 충돌은 각 시나리오의 기대 조건을 검사하며, 실패 응답이나 판정에 필요한 결과가 없는 경우는 기준 미충족이 아니라 관측 불가로 구분한다. 상세 기준과 재현 방법은 [README](README.md)의 #84 집계 절을 따른다.

## 기존 최종 실행: GPT-4.1 strict

원본: [results-live-gpt41-final.json](results-live-gpt41-final.json), `gpt-4.1-2025-04-14`, 사례당 1회.

| 항목 | 집계 |
| --- | --- |
| 사례별 기대 조건 | 정상·불일치·정책 미정·원문 충돌 각 1건 통과; 관측 불가 0건 |
| 정상 사례의 BLOCKING 오탐 | 0 / 관측 가능한 정상 사례 1건. 비차단 finding의 정확성까지 보증하지 않음 |
| 불일치·원문 충돌·정책 미정 기준 미충족 | 각 0 / 관측 가능한 해당 사례 1건 |
| 입력·출력 토큰 | 각각 7,284·567. 4개 usage 기록 모두 토큰 수 보고 |
| 모델 호출 지연 | 보고된 `latency_ms` 4건 합계 8,514ms. BE·DB·검색 및 화면의 종단 간 지연 아님 |
| 모델 usage 실패 | 실패로 표시된 기록 0 / 보고된 4건 |
| 비용 | 4건 모두 금액 정보 없음. 비용 합계·실제 청구액은 알 수 없음 |

재현: `python -m evaluations.validation.summary evaluations/validation/results-live-gpt41-final.json`. 이전 `gpt-4o-mini` 및 GPT-4.1 중간 실행도 같은 명령에 각 원본 JSON을 전달하면 집계할 수 있다. 원본의 provider 응답이 캡처된 뒤 공개 오류로 반환된 경우는 `model_output_then_rejected`로 구분하지만, 공개 오류만으로 파싱 실패인지 다른 출력 검증 실패인지는 단정하지 않는다.

## 남은 일

- 독립적으로 검토한 별도 평가셋과 반복 실행으로 오탐·누락, 실패, 지연·실제 비용을 측정한다. 기존 4건을 독립 홀드아웃으로 재분류하지 않는다.
- 실제 BE·검색·권한·DB·운영 모델 설정을 포함한 전체 경계는 별도 환경에서 검증한다. #209의 11/10~11/13 인수 검증 결과와 구분한다.
- AC-16은 #247에서 작업의 최신 검증이 동일 리비전·기준·입력 해시·규칙 버전의 정상 완료된 규칙 전용 PASS일 때 권한·규칙 재확인 후 재사용한다. 검색·모델 결과 재사용은 미구현이다. [제안 정책](../../../docs/design/validation-evaluation-reuse-S15P31A108-84.md)을 백엔드·검색 담당과 합의하고, 실제 구현과 무효화 회귀 검증 후에만 해당 재사용 효과를 기록한다.
